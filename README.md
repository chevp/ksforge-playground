# ksforge-playground

Sammlung unabhängiger Proof-of-Concepts. Jeder `poc-NN-<stack>`-Ordner ist eigenständig lauffähig, ohne Abhängigkeiten zu anderen POCs.

| Ordner | Stack | Zweck |
| --- | --- | --- |
| [poc-01-rust-cli](poc-01-rust-cli) | Rust (CLI) | |
| [poc-02-rust-llm](poc-02-rust-llm) | Rust | |
| [poc-03-vuejs](poc-03-vuejs) | Vue 3 + Vite | |

## Konvention

Neue POCs als `poc-NN-<kurzname>` anlegen, `NN` fortlaufend zweistellig.
